## About

**Dexterous-Manipulation-Frontier** is a curated list for the ecosystem around dexterous robot manipulation: dexterous hands, tactile sensing, hand-centric tasks, robot learning, optimal control, teleoperation, benchmarks, datasets, and simulators.

This list is intentionally **dexterity-first**. It includes strong adjacent manipulation work only when it materially helps understand, build, evaluate, or deploy dexterous manipulation systems.

> **Note**: The full detailed tables and curated content are being migrated from the original Awesome-Dexterous-Manipulation repository. Please refer to the original for the complete current list while this is being updated.
